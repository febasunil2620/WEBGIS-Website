# Sulthan Bathery Municipality WebGIS Platform
**സുൽത്താൻ ബത്തേരി നഗരസഭ • ഔദ്യോഗിക വെബ് ജി.ഐ.എസ് പോർട്ടൽ**

Official WebGIS Platform and Spatial Information System for **Sulthan Bathery Municipality**, Wayanad District, Kerala, India.

---

## 🗺️ Key Features

1. **Interactive WebGIS Spatial Viewport**:
   - Integrates the live WebGIS engine hosted at: [https://febasunil2620.github.io/WEBGIS-SULTHAN-BATHERY/](https://febasunil2620.github.io/WEBGIS-SULTHAN-BATHERY/).
   - Fullscreen mode, reload view, and direct tab launch.
   - Clean, focused cartographic viewport without distraction.

2. **Official Demographics & Ward Spatial Directory**:
   - Filterable catalog of all **36 delimited municipal wards** sourced from the official GIS survey dataset (`warddetails.xlsx`), including surveyors, delimitation remarks, landmarks, and zones.
   - Demographic indicators: ~45,417 population, 89.4% literacy, 10,230 households, and indigenous tribal composition.

3. **Highland Geography & Ecological Corridors**:
   - Topographical elevation (900m – 1,000m MSL) on the Deccan Plateau–Western Ghats transition.
   - Contiguous boundaries with the **Wayanad Wildlife Sanctuary** and **Nilgiri Biosphere Reserve** (Bandipur & Mudumalai corridors).
   - Eastward drainage basin feeding the Kabini River tributaries.

4. **History & Heritage Chronicle**:
   - Prehistoric context: **Edakkal Cave petroglyphs** (6000 BCE).
   - Historical roots: Ancient **Ganapathivattam** (8th Century).
   - Vijayanagara architecture: **13th-century Bathery Jain Temple**.
   - Artillery depot: **Tipu Sultan's Battery** and British renaming to "Sultan's Battery".
   - Anti-colonial struggles: **Veera Pazhassi Raja's** guerrilla warfare with Kuruma and Kurichiya archers.

5. **Clean City Sulthan Bathery Model**:
   - Showcase of the award-winning zero-waste municipal initiative, 100% source segregation, Haritha Karma Sena operations, and flower-lined pedestrian trails.

## 🚀 How to Run and View the Platform

### Option 1: Direct File Access
Simply double-click [`index.html`](file:///c:/GIS%20pr/antigravity_webgis/index.html) to open the platform in any modern web browser (Google Chrome, Microsoft Edge, Firefox).

### Option 2: Local Web Server
Run a local HTTP server:
```bash
npx http-server . -p 8080 -c-1
```
Then visit:
```
http://localhost:8080/index.html
```
